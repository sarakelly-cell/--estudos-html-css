Parte 2: Cheatsheet (Resumo de propriedades)

Use estes cards como um guia rápido para relembrar as propriedades e seus valores.
Dividimos entre o que vai no Elemento 'PAI' e o que vao no Elemento 'FILHO'.

Elemento 'PAI'

Propriedades do Container.

Display

Ativar o contexto flex.

valores:

  • flex (em bloco)
  • inline-flex (em linha)

flex-direction

Define o eixo principal.

valores:

  • row, row-reverse
  • column, column-reverse

justify-content

Alinhamento do eixo principal

valores:

  • flex-start, flex-end
  • center
  • space-between, space-around

flex-wrap

Quebra de linha.
Valores:
  • nowrap, wrap
  • wrap-re

align-items

Alinhamento no Eixo Cruzado

valores:

  • stretch, center
  • flex-start, flex-end
  • baseline

Gap

Espaçamento entre os itens
Exemplos:
  • gap: 10px;
  • gap: 10px 20px;

Elemento Filhos

Propriedades do Container

align-sel

Sobrescreve o align-items para um item especifico

valores:

  • auto, center, flex-start, stretch

flex-grow / shrink

Capacidade de crescer ou encolher para preencher o container.

valores:

  • 0(não altera)
  • 1, 2, etc. (proporção)

order

Altera a ordem visual de exibição

valores

  • 0(padrão)
  • -1(vai pro inicio)
  • 1(vai pro final)
